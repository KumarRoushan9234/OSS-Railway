# oss-railway

Install OSS Railway, a self-hosted PaaS, on a Linux server.

> **Work in progress.** Still being built and not yet tested on many real servers. Don't use it for anything critical yet. Source, docs and status: https://github.com/KumarRoushan9234/OSS-Railway

```sh
npx oss-railway setup root@203.0.113.10 [-p 22] [-i ~/.ssh/id_ed25519]   # over SSH
sudo npx oss-railway install                                            # on the server
```

Then open the printed URL and enter the setup code.
