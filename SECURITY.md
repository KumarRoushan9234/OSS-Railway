# Security

OSS Railway controls Docker on your server, which is the same as root access. Treat the dashboard like an SSH login: use a strong password, turn on two-factor sign-in or a passkey, and keep it on HTTPS.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private reporting instead:
[Security → Report a vulnerability](https://github.com/KumarRoushan9234/OSS-Railway/security/advisories/new).

Include what you found, how to reproduce it, and which version you ran. I'll reply as soon as I can and credit you in the fix unless you'd rather not be named.

## Status

This project is in early development (alpha). It has not had an independent security review. See the "Known limits" section of [docs/ROADMAP.md](docs/ROADMAP.md).
